# Classify Images with TensorFlow on Google Cloud

![Google Cloud](https://upload.wikimedia.org/wikipedia/commons/5/51/Google_Cloud_logo.svg)

This repository contains all the labs and materials from the **Classify Images with TensorFlow on Google Cloud** course on **Google Cloud Skills Boost**. The course focuses on building and training machine learning models for image classification using **TensorFlow** and **Vertex AI**.

---

## 📌 **Course Overview**
This course teaches you how to:
- Use **TensorFlow** for image classification.
- Apply **convolutional neural networks (CNNs)** for improved performance.
- Train and deploy models using **Vertex AI** on Google Cloud.
- Work with **Google Cloud Workbench** and **Jupyter Notebooks**.

Upon completion, a **Google Cloud Skill Badge** is awarded to recognize proficiency in TensorFlow-based image classification.

---

## 🚀 **Labs Included**
The repository contains materials and solutions for the following labs:

| Lab No. | Lab Title | Duration |
|---------|-------------------------------------------|------------|
| 1️⃣ | **TensorFlow: Qwik Start** | 45 minutes |
| 2️⃣ | **Introduction to Computer Vision with TensorFlow** | 1 hour |
| 3️⃣ | **Introduction to Convolutions with TensorFlow** | 50 minutes |
| 4️⃣ | **Classify Images with TensorFlow CNNs** | 1 hour 15 minutes |
| 5️⃣ | **Identify Horses or Humans with TensorFlow and Vertex AI** | 1 hour 30 minutes |
| 6️⃣ | **Challenge Lab: Classify Images with TensorFlow on Google Cloud** | 1 hour 30 minutes |

Each lab is designed to build on the previous ones, covering **data preprocessing, model training, and deployment**.

## 📥 **How to Use This Repository**
1. **Clone the Repository**
   \`\`\`sh
   git clone https://github.com/your-username/Classify-Images-TensorFlow-GCloud.git
   cd Classify-Images-TensorFlow-GCloud
   \`\`\`
2. **Set Up Your Environment**
   - Install TensorFlow:
     \`\`\`sh
     pip install tensorflow
     \`\`\`
   - Install Google Cloud SDK:
     \`\`\`sh
     curl https://sdk.cloud.google.com | bash
     gcloud init
     \`\`\`
   - Enable Vertex AI in your Google Cloud project.

3. **Run Jupyter Notebook**
   \`\`\`sh
   jupyter notebook
   \`\`\`
   Open the notebook file and run the cells.
